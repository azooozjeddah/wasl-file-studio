# تقرير قبول مستقل — Wasl File Studio

## التغطية المنفذة

اعتمدت الجولة على عينات محلية غير حساسة، وعلى جلسة Firefox مستقلة داخل بيئة المشروع؛ لم تعتمد على متصفح المستخدم أو بقائه مفتوحًا. شمل الفحص **55 مسارًا عامًا** في الكتالوج، مع تحقق قبول لمخرجات PDF وExcel والتحقق من الملفات، واختبار رفع ومعالجة وتنزيل مستقل لتغيير حجم صورة PNG.

| المجال | ما تم التحقق منه |
|---|---|
| المسارات والكتالوج | جميع المسارات العامة أعادت حالة نجاح، والأدوات غير الموثوقة تعرض «قريبًا» بدل مساحة معالجة. |
| PDF | عينات دمج وإعادة حفظ قابلة للقراءة ومخرجات غير فارغة؛ فحص المقارنة يعتمد عامل المتصفح وتمت مراجعته بصريًا سابقًا. |
| Excel | XLSX/CSV والمعاينة العربية ومخرجات المصنف تحققت بعينات محلية. |
| الصور | رفع PNG، معاينة، تغيير الحجم، إنشاء WebP، وتنزيله تحققت آليًا في Firefox مستقل. |
| الحساب والحماية | حماية `/dashboard` تعيد غير المسجل إلى `/login`، وتغطية اختبارات المصادقة والصلاحيات ناجحة. |

## العيوب التي عُثر عليها وأُصلحت

تم إصلاح رابط إنشاء الحساب الذي كان يعيد 404، ومنع الروابط المباشرة للأدوات المؤجلة من فتح مساحة معالجة، وتحسين منطقة اختيار الملف كي تعمل كتسمية مرتبطة بحقل الملف مع الإبقاء على السحب والإفلات. كما أضيف مسار فك بديل للصور عند تعذر `createImageBitmap`؛ نجح تغيير الحجم والتنزيل بعده في Firefox المستقل.

## القيود المعروفة

يوجد تحذير Firefox واحد متعلق بمورد شعار خارجي تديره طبقة النشر (`files.manuscdn.com`). لم يظهر هذا المورد في DOM أو CSS أو رأس الصفحة، ولا يؤثر في التحميل أو المعالجة؛ يمنع المصدر المحلي للعلامة عرضه داخل الواجهة. لا يمكن تغيير إعداد طبقة النشر هذه من مصدر التطبيق دون تعديل إعداد مستضاف خارج الكود، ولذلك وُثّق كقيد وليس كعطل وظيفي.

## النتيجة

نجح `pnpm check`، ونجحت **39 مجموعة اختبار / 91 اختبارًا**، كما نجحت حزمة قبول PDF وExcel والتحقق من الملفات ومسارات الكتالوج. النسخة **جاهزة لاختبار المستخدم النهائي**، مع التذكير بأن الأدوات التجريبية واضحة بحالة «قريبًا» وليست متاحة للمعالجة.
