# نماذج بصرية مستقلة لـ وَصَل للملفات

> **حالة النماذج:** تصورات مرئية فقط. لم يتغير كود التطبيق أو تصميمه الحالي أو Production، ولم تُعتمد هوية نهائية.

## نظرة مقارنة

كل اتجاه يعرض الصفحة الرئيسية على سطح المكتب والجوال، ويضم الهيدر، منطقة الرفع، حالة مساعد الملفات بعد PDF، بطاقات الأدوات والتصنيفات، لمحة QR، FAQ، الفوتر، ورمزًا بصريًا مؤقتًا للهوية. الاختلاف بين الاتجاهات ليس لونيًا فقط؛ بل يغيّر طريقة تقديم المنتج وأولوية العناصر في أول رحلة للمستخدم.

| الاتجاه | الفكرة الأساسية | ما يتصدر الصفحة | الانطباع | الأنسب عندما تكون الأولوية |
|---|---|---|---|---|
| **A — Premium Minimal** | أقل خطوات، أقصى وضوح | ملف واحد وقرار واحد | هادئ، فاخر، تحريري | البساطة والثقة والوضوح العام |
| **B — Smart File Assistant** | الملف أولًا ثم توصية واعية | مساعد الملفات | حديث، موجّه، ودود | رفع الملفات من الجوال ومساعدة غير التقنيين |
| **C — Professional File Studio** | منصة ملفات شاملة ومنظمة | التصنيفات ومسارات العمل | ناضج، تجاري، مؤسسي | الشركات والمستخدمون المتكررون وتوسع الأدوات |

## Concept A — Premium Minimal

### سطح المكتب

![Concept A Desktop](/manus-storage/wasl-concept-a-premium-desktop_24a2485b.png)

يرى المستخدم شعارًا مجردًا لوصل مستندين، وهيدرًا قصيرًا، ثم عنوانًا تحريريًا ومساحة رفع مركزية. أدوات المنصة تظهر كاختيار منسق لا ككتالوج مزدحم؛ في حالة PDF تتقدم توصيات ضغط PDF والتوقيع والتقسيم على شكل بطاقات دقيقة. يكتمل المسار بمظهر هادئ لـ QR وFAQ وفوتر بسيط.

### الجوال

![Concept A Mobile](/manus-storage/wasl-concept-a-premium-mobile_33067236.png)

تحتفظ نسخة الجوال بالفراغ والتنفس البصري: الرفع أولًا، ثم ملخص PDF وحالة المعالجة المحلية، ثم ثلاث توصيات فقط. تتقلص التصنيفات وFAQ إلى شرائط قابلة للمسح، لتبقى الصفحة فائقة الوضوح بيد واحدة.

| المكوّن | المعالجة البصرية في A |
|---|---|
| الشعار والهوية | رمز مستندين متصلين، حبر داكن، بنفسجي كهربائي محدود، وخلفية عاجية. |
| Header / Navigation | هيدر أبيض نحيف وروابط قليلة وزر إجراء بنفسجي واحد. |
| Hero والرفع | عنوان تحريري كبير وكائن رفع ورقي أنيق في المركز. |
| مساعد الملفات | حالة PDF مصغرة ذات أسباب توصية قصيرة وغير مزعجة. |
| بطاقات الأدوات | شبكة صغيرة غير متساوية، أيقونات خطية، وحالة معالجة محلية هادئة. |
| QR / FAQ / Footer | لمحة QR صغيرة، صف FAQ قليل التشويش، وفوتر متحفظ. |

## Concept B — Smart File Assistant

### سطح المكتب

![Concept B Desktop](/manus-storage/wasl-concept-b-assistant-desktop_18d0a77c.png)

هذا الاتجاه يجعل وعد المنتج صريحًا: **«ارفع ملفك، وَصَل يعرف ماذا يحتاج»**. منطقة الرفع هي أكبر عنصر، وبعدها تتشكل رحلة مرئية من الملف إلى توصية أساسية ثم بدائل جاهزة فقط. المعلومات المعروضة هي اسم الملف والحجم وعدد الصفحات وحالة المعالجة المحلية وسبب كل اقتراح، من دون تحويل المساعد إلى روبوت محادثة.

### الجوال

![Concept B Mobile](/manus-storage/wasl-concept-b-assistant-mobile_47a9be3b.png)

يظهر المساعد مباشرة تحت الهيدر كواجهة عمل لا كقائمة أدوات. بطاقة PDF تحدد الملف والصفحات والخصوصية، ثم تبرز «ضغط PDF» كخطوة مقترحة وتبقي التوقيع والتقسيم واستخراج النص كبدائل مختصرة. تظهر التصنيفات وQR وFAQ بعد إنهاء السياق الأساسي للملف.

| المكوّن | المعالجة البصرية في B |
|---|---|
| الشعار والهوية | ملف مع بريق صغير وعقد اتصال؛ بنفسجي وPeriwinkle ونعناعي للحالات السليمة. |
| Header / Navigation | هيدر حديث قصير، يترك مساحة بصرية للمساعد بدلاً من الملاحة. |
| Hero والرفع | مساعد ملفات كبير منقسم إلى «اختر ملفًا» ثم «ماذا يمكن فعله؟». |
| مساعد الملفات | تسلسل واضح: ملف → توصية رئيسية → بدائل جاهزة مع أسباب. |
| بطاقات الأدوات | خفيفة، ملونة حسب النوع، ولا تظهر قبل سياق المساعد إلا كبديل يدوي. |
| QR / FAQ / Footer | QR بحالة تحقق واضحة، FAQ قصير، وفوتر يركز على الخصوصية المحلية. |

## Concept C — Professional File Studio

### سطح المكتب

![Concept C Desktop](/manus-storage/wasl-concept-c-studio-desktop_2a4afe30.png)

يعرض هذا الاتجاه وَصَل كمنصة SaaS ناضجة: هيدر منظم، تصنيفات أدوات محددة، ومسارات عمل مفهومة. لا يختفي المساعد، لكنه يصبح طبقة تسريع داخل منصة أشمل؛ يظهر ملخص PDF والتوصية والحالة المحلية ضمن سياق مهني يصلح للفرد والفريق.

### الجوال

![Concept C Mobile](/manus-storage/wasl-concept-c-studio-mobile_b097c9ad.png)

تبدأ النسخة المحمولة بعنوان «استوديو ملفات ينجز العمل»، ثم بوابة رفع مدمجة، ثم تصنيفات PDF والصور والمستندات وExcel وQR. بعد ذلك يقدم المساعد توصية واضحة، بينما تحفظ بطاقات الأدوات الهوية التجارية الهادئة وQR وفوترًا منظمًا.

| المكوّن | المعالجة البصرية في C |
|---|---|
| الشعار والهوية | رمز هندسي لملف متصل؛ كحلي تجاري وبنفسجي ملكي ونعناعي لحالة النجاح. |
| Header / Navigation | تنقل أوضح: الأدوات، الحلول، الخصوصية، وإجراء أساسي. |
| Hero والرفع | وعد تجاري قوي وبوابة رفع مدمجة بجوار مسار العمل. |
| مساعد الملفات | تفاصيل الملف ضمن لوحة تحقق محلي، مع توصية وبدائل منضبطة. |
| بطاقات الأدوات | تصنيفات مستقلة بمقاييس وأيقونات موحدة وحالات جاهزية دقيقة. |
| QR / FAQ / Footer | QR كأداة ضمن المنصة، FAQ أعمال منظم، وفوتر متعدد الأعمدة. |

## كيفية الاختيار

اختر **A** إذا أردت علامة هادئة وفخمة تجعل معالجة الملفات تبدو بسيطة جدًا. اختر **B** إذا كان وعد المنتج الرئيسي هو مساعدة المستخدم على معرفة الأداة المناسبة بعد رفع ملفه. اختر **C** إذا أردت أن يُفهم وَصَل كمنصة تجارية كاملة قابلة للنمو مع كثافة أدوات وفئات أعلى.

لا تبدأ أي خطوة تصميم أو تعديل أو نشر قبل اختيار اتجاه واحد صراحةً.
