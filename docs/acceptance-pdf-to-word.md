# قبول PDF إلى Word

**النطاق:** مسار PDF النصي القابل للاستخراج فقط. لا يشمل OCR أو الاسترجاع البصري لتخطيط PDF.

| الاختبار | النتيجة |
|---|---|
| محرك المتصفح مع `sample.pdf` حقيقي | أنشأ `sample-editable.docx` بحزمة ZIP سليمة وملف TXT؛ المحتوى المستخرج `Dummy PDF file`. |
| محرك المتصفح مع `qa-alpha.pdf` حقيقي | أنشأ `qa-alpha-editable.docx` وTXT بالمحتوى `Wasl QA Alpha Local PDF fixture Amount: 120`. |
| فحص DOCX الفعلي | اجتاز `unzip -t` واحتوى `word/document.xml` على النص المتوقع. |
| Production: رفع ومعالجة وتنزيل | نجح من واجهة `/pdf-to-word`؛ أظهر ملف DOCX بحجم 8.3KB وTXT بحجم 43B، ونفّذ تنزيل النتائج. |
| PDF مصوّر حقيقي | رُفض برسالة: «هذا PDF لا يحتوي نصًا قابلًا للاستخراج. استخدم أداة OCR للملفات الممسوحة ضوئيًا أولًا.» |
| الجوال | فُحصت واجهة Production عند 375×812 دون تعطيل تدفق الواجهة. |

> القيد المقصود: هذه أداة تحويل نصي إلى DOCX، وليست محولًا بصريًا يحافظ على التصميم الأصلي أو الجداول أو الصور في PDF.
