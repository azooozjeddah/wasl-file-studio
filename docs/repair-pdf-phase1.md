# Repair PDF — المرحلة الأولى

## النطاق والقرار

اقتصر التعديل على `repair-pdf`. لم تتغير OCR أو QR أو PDF→Word أو أي Lifecycle. بقيت `repair-pdf` Disabled إلى حين قرار قبول مستقل؛ لا يعني هذا التعديل أنها Ready.

## السلوك الجديد

تعيد `repairPdf` حفظ PDF الذي يستطيع `pdf-lib` قراءته وتتحقق من المخرج باستخدام PDF.js مستقل. تتحقق من عدد الصفحات وتستخرج نصًا لتأكيد أن المخرج قابل للتحليل. النتيجة المعروضة للمستخدم واحدة من:

| الحالة | المعنى |
|---|---|
| `Repaired` | لا تظهر إلا إذا وُجدت إشارة `startxref` غير صالحة، وفشل المدخل في PDF.js مستقل، ثم نجح المخرج بعد الحفظ. |
| `Re-saved / No repair required` | المدخل قابل للقراءة في PDF.js؛ لا تدعي الأداة إصلاحه، حتى لو احتوى xref غير معياري. |
| `Unsupported / Password protected` | ملف محمي؛ لا توجد محاولة لتجاوز كلمة المرور. |
| `Unsupported` | ليس PDF صالحًا. |
| `Unrepairable / <reason>` | فشل parser بنيوي، مثل `xref` أو `trailer` أو `page-tree` أو `stream` عندما يمكن استنتاج السبب. |

ينسخ المسار bytes قبل تسليمها إلى PDF.js لأن PDF.js قد ينقل buffer إلى العامل؛ هذا يمنع تنزيل Blob فارغ بعد تحقق المخرج.

## القبول الفعلي

| العينة | النتيجة | الإثبات |
|---|---|---|
| PDF إنجليزي سليم | Re-saved | صفحة 1/1، PDF.js مستقل، تنزيل 995 B يبدأ بـ`%PDF-`. |
| PDF صوري من 6 صفحات | Re-saved | صفحات 6/6، تنزيل 578,075 B، صور ومحتوى مرئي محفوظان. |
| PDF Unicode عربي/إنجليزي من صفحتين | Re-saved | صفحات 2/2، تنزيل 8,380 B، RTL والنص محفوظان. |
| `startxref` مكسور | Re-saved | فشل `pdfinfo` لكنه قُبل من PDF.js؛ لا يحقق شرط `Repaired` الصارم. |
| محمي بكلمة مرور | Unsupported / Password protected | لا مخرج ولا تجاوز للحماية. |
| ملف باسم PDF لكنه ليس PDF | Unsupported | لا مخرج. |
| PDF يحمل header فقط بلا page tree | Unrepairable / page-tree | لا مخرج. |

## التحقق الآلي

نجح `pnpm check` واختبار `client/src/lib/pdf-engine.repair.test.ts` (3/3). نجح بناء الإنتاج المحلي. المجموعة الكاملة بقي فيها فشل سابق غير متعلق بهذه المرحلة في `file-handoff.test.ts`: يتوقع أن PDF→Word غير Ready، بينما Baseline المعتمد يجعله Ready؛ لم يتغير خارج نطاق repair-pdf.

## الحدود الباقية

لا يعيد المسار بناء page tree أو streams أو كائنات مفقودة، ولا يسترجع PDF لا يستطيع `pdf-lib` فتحه، ولا يفتح PDF محميًا. لم تنتج العيّنات المتاحة حالة `Repaired` بالشرط الصارم؛ ولذلك لا يجوز تسويق الأداة كإصلاح شامل للـPDF.
